# Sticky Windows

Website, downloads, and the Sparkle update feed for **Sticky Windows**, a macOS app that parks any window as a tab on the edge of your screen.

- Website: https://stickywindows.com/
- Downloads: [Releases on the app repo](https://github.com/aaronfisher/StickyWindows/releases)
- Update feed: `appcast.xml` (used by the app's auto-updater; don't edit by hand)
